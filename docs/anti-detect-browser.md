# Anti-detect browser — what it is & top tools (2026)

Hub page for [Anti-Detect Browser Comparison](../README.md).

## Definition

An **anti-detect browser** (antidetect browser, **fingerprint browser**, **browser antidetect**) runs isolated profiles with unique device fingerprints — canvas, WebGL, fonts, timezone, hardware — so platforms treat each profile as a separate device.
